## Building

### Requirements

- Python with venv installed
- Git

### Windows(Powershell)

```ps1
git clone https://github.com/1-Black-Fox-1/smpl
cd smpl
python -m venv src\venv
src\venv\Scripts\pip install -r requirements-win.txt
.\scripts\build.ps1
```

### Linux

```bash
git clone https://github.com/1-Black-Fox-1/smpl
cd smpl
python -m venv src/venv
src/venv/bin/pip install -r requirements.txt
./scripts/build.sh
```
